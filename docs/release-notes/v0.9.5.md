## What's new in 0.9.5

- **New Ubuntu Virtual Machine works from the installed app.** In 0.9.4 it stopped at once with
  "The type name 'HashSet' could not be found". PowerShell was starting in the app's own folder,
  where .NET's copies of Windows' assemblies sent the build's small C# helpers to the wrong ones.
  Every PowerShell the app runs now starts in Windows' System32 folder instead, which also means
  nothing in the app's folder, which your account can write to, can be picked up by the
  PowerShell it runs as administrator.
