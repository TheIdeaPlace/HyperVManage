## What's new in 0.9.9

- **Choose the columns.** View, Columns… (Alt+W, C) shows, hides and reorders the VM list's
  columns. There are new ones to turn on: **Location**, the folder each VM is kept in; **Disks**,
  its virtual hard disk files; and **Checkpoints**. Each row is read as its columns, in the order
  they're shown, so what you hear is what's on screen. **Speak column names**, on to begin with,
  reads each column but the first with its name ("Network: External Wi-Fi"). In the dialog, Enter
  adds a column; Delete removes one; Alt+Up, Alt+Down, Alt+Home and Alt+End move it; and each says
  what happened, such as "Location moved above Memory". A Preview shows the selected VM as it will
  be read. Your columns and their widths are kept for next time.
- **Keep a VM where you like.** New Windows Virtual Machine, New Ubuntu Virtual Machine and Clone
  have a Location box, with Choose Folder, for keeping the VM somewhere other than the system
  drive, such as an external SSD. The VM gets a folder of its own there, with its disks inside,
  and the sentence under the box says where it will go. Leave it empty for Hyper-V's usual
  folders. The location you used last is offered next time.
- **Drives Hyper-V can't use are caught first.** A location on a drive that isn't plugged in, or
  one formatted exFAT or FAT32 (as many external drives come), is refused in the form with a note
  saying why, rather than partway through a build. Hyper-V needs NTFS or ReFS.
- **Clone asks where, and checks there's room.** Clone now asks for the copy's name and location
  in one dialog, and checks first that there's room for the copy and the temporary export it's
  made from.
- **Tidier deletes.** Deleting a VM kept in a location of its own removes its folder too, once
  nothing is left in it; so does stopping a build partway.
- **For the command line:** New-HyperVRdpVM.ps1 has a new `-Location` parameter that does the same.
