## What's new in 0.9.3

- **An installer, and automatic updates.** HyperVManage-Setup-x64.exe and
  HyperVManage-Setup-arm64.exe install Hyper-V Manage for your account, with a Start menu
  entry. From then on it checks for a new version each time it starts, downloads it while you
  work, and installs it when you close the app. Help, Check for Updates checks straight away and
  can install at once. The single exe is still here for running without installing; it tells you
  when there's a new version.
- **Help, Report a Bug.** Say what happened and send it, with the app's version, Windows' version,
  the processor and which screen reader is running, and nothing about your VMs. Send with GitHub
  opens GitHub's new issue form in your browser with the report filled in.
- **ISOs you've used before.** New Virtual Machine's Windows ISO is now a list: the ISOs you've
  built VMs from, the last one already chosen, then the newest in Downloads, then Browse for an
  ISO, which opens the file dialog. No more finding the same ISO every time.
- **Its own home.** Hyper-V Manage now lives at
  [kellylford/HyperVManage](https://github.com/kellylford/HyperVManage), with its history. Releases
  before this one stay at [TheWorkBench](https://github.com/kellylford/TheWorkBench/releases?q=hyperv-manage).
- About shows the release's own version.

The single exe from 0.9.2 and earlier doesn't update itself: download the installer once, and it
keeps itself up to date from then on.
