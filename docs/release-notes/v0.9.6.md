## What's new in 0.9.6

- **A list of each VM's checkpoints** ([#13](https://github.com/TheIdeaPlace/HyperVManage/issues/13)).
  Under the list of VMs, and next to it in Tab order, is the selected VM's list of checkpoints,
  newest first, each read with when it was taken and whether it's the one the VM is now based on.
  - **Enter** applies the checkpoint, in the same window as Apply Checkpoint, with that checkpoint
    already chosen.
  - **F2** renames it.
  - **Delete** deletes it, after asking. Choose several with Shift or Ctrl and the arrow keys and
    one question deletes them all, so clearing out old checkpoints is quick. You can no longer take
    the VM back to a deleted checkpoint, but the VM itself and its other checkpoints don't change.
    Focus moves to the next checkpoint, so you can keep going.
  - **Shift+Delete** deletes a checkpoint and every one taken after it; the question names them.
  - The same actions are on the new **Checkpoints** menu (Alt+C) and the list's context menu
    (Shift+F10). F5 reads the list again, and it follows checkpoints made or deleted elsewhere.
- **Help, Download Ubuntu** ([#11](https://github.com/TheIdeaPlace/HyperVManage/issues/11)).
  The Help menu now has Ubuntu 26.04 LTS beside the Windows downloads: it opens ubuntu.com's
  download folder for this PC's processor, the one New Ubuntu Virtual Machine downloads from.
  The build still downloads Ubuntu itself, but uses the newest desktop ISO from your Downloads
  folder instead when it's there under the name it downloaded with.
- **Escape answers No.** The questions that ask before deleting a VM or checkpoints, stopping a
  build, or installing an update now close with Escape, Alt+F4 or the close button, and that
  answers No. Before, Escape did nothing and you had to Tab to No. No has focus to begin with,
  except for the update question, which starts on Yes as before. Deleting and stopping still play
  the warning sound.
- **Plainer Delete questions.** Deleting a VM says what goes, the VM, its checkpoints and its
  disk files, and says it's turned off first only when it's running. Deleting checkpoints says
  you can no longer take the VM back to them, and that the VM and its other checkpoints don't
  change. Both end with "This can't be undone."
