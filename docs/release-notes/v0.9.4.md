## What's new in 0.9.4

- **New Ubuntu Virtual Machine** (File menu, Ctrl+Shift+N). It builds an Ubuntu 26.04 LTS
  desktop VM with no installer questions and the Orca screen reader on, then opens Remote
  Desktop straight to the desktop, with Orca already talking and its speech playing on your PC.
  There's no second sign-in. Give it a name, a user name and password, and its processors,
  memory and disk, as for Windows; **Orca screen reader on from the start** is checked to begin
  with.
  - Ubuntu is downloaded from ubuntu.com the first time, about 4 GB on an Arm PC and 6.5 GB on
    others. It's checked against Ubuntu's own checksums and kept for the next one. A download
    that stops partway carries on next time.
  - Hyper-V gives a VM no sound card, so the sound comes over Remote Desktop, as it does for
    Windows. Hyper-V's "enhanced session" for Linux is Remote Desktop too, but through a program
    Ubuntu's desktop no longer works with, so the VM uses GNOME's own Remote Desktop instead.
  - The Hyper-V console shows only Ubuntu's sign-in screen, and has no sound. Screenshot shows
    that screen without asking for a sign-in, and Run Windows OCR reads it, which helps if the
    install stalls.
  - The install takes 20 to 40 minutes, and the build says how far it has got every three
    minutes.
  - So far it has been built end to end on an Arm64 PC; x64 PCs take the same steps but haven't
    been tried yet.
- New Virtual Machine is now **New Windows Virtual Machine**, still on Ctrl+N.
- `New-HyperVRdpVM.ps1 -Ubuntu` does the same from the command line. See the script's
  [README](https://github.com/TheIdeaPlace/HyperVManage/tree/main/hyperv-rdp-vm#ubuntu).
