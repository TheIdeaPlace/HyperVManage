## What's new in 0.9.8

- **Windows Server VMs.** New Windows Virtual Machine now builds from a Windows Server ISO, such
  as the Windows Server 2025 Evaluation, as well as Windows 11. The build gives Server the extra
  answers it needs to set itself up with nothing from you: simple passwords like the default
  vmadmin are allowed, the built-in Administrator gets the same password, Server Manager doesn't
  open at every sign-in, and the Shutdown Event Tracker doesn't ask why at every restart. Sound
  works over Remote Desktop: Server ships with its audio services turned off, and the build turns
  them on to stay on. The suggested name ends in -Server rather than -Win11.
- **Choose the edition from a list.** The Edition box is now a list of the editions in the chosen
  ISO, filled a moment after the ISO is chosen, so there's no exact name to type. Pro is chosen
  on a Windows 11 ISO; on a Server ISO, Datacenter with the desktop. Editions without "(Desktop
  Experience)" are Server Core, which has no desktop, and the build says so if you choose one.
  When choosing another ISO changes the edition, the new edition is read out. You can still
  type an edition yourself.
- **A wrong edition is caught in the form.** An edition the ISO doesn't have is now refused
  when you press Create, with a note to choose one from the list, rather than partway through
  the build.
