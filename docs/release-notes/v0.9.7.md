## What's new in 0.9.7

- **The arrow keys read the build's output.** In New Virtual Machine, the Progress box now has a
  caret, so JAWS and NVDA can arrow up through the lines, including the error that says why a
  build stopped. Before, the arrows read nothing there.
- **Each build's output is saved.** When a build ends, however it ends, the output is saved to
  `%LOCALAPPDATA%\HyperVManage\Logs`, in a file named for the VM and the time, so you can read it
  after closing the window or attach it to a bug report. The last line in Progress gives the
  file's full path. The line where the script prints the password is blanked out in the file.
- **The arrows stay in the lists.** With no VMs, Up or Down in the empty list moved focus to the
  menu bar. The arrows, Home, End, Page Up and Page Down now stay in the VM list and the
  checkpoint list.
